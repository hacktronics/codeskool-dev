REUSABLE 3D CONTENT

Original scenery and actor geometry. CodeSkool property, all rights reserved.

The environments and sprites folders contain self-contained GLB models, rendered thumbnails and JSON manifests. All of them are in the 3D library: Choose a 3D Object, the worlds are under the Worlds tag. The importer normalizes a model to one unit; apply scale3d (environments) or projectScale3d (actors) using Transform > set all scale to. Multiply world positions by 36 for Transform position blocks.

Keep scenery stationary. Use separate character, ball and checkpoint sprites for gameplay interactions. The examples show proximity checks using the existing AI blocks.

Finished projects, previews and build guides are under /static/examples/. No new renderer, blocks, controller interface or backend is required.
