REUSABLE 3D CONTENT

Original scenery and actor geometry. CodeSkool property, all rights reserved.

The environments and sprites folders contain self-contained GLB models, rendered thumbnails and JSON manifests. Select Stage and use Choose an Environment for the worlds in environments/manifest.json. Use Choose a 3D Object for the actor models in sprites/manifest.json. The Stage chooser applies each environment's scale3d automatically. For actors, use Transform > set all scale with projectScale3d and Transform > go to x/y/z for positions (36 position units equal one world unit).

World geometry belongs to the Stage ground model and is not a sprite. Characters, cars, balls, chests and checkpoint gates remain separate sprites with editable block rules. The examples use the existing AI proximity blocks for gameplay interactions.

Finished projects, previews and build guides are under /static/examples/. Choose the Stage environment first, then add and program the actor sprites through the main interface.
