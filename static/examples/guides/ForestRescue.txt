Forest Rescue
=============

Reach the three orange hikers along the forest paths. Arrow keys move the ranger. Each rescued hiker disappears; the ordinary Text blocks update the floating mission label. Green flag restarts all hikers. Use AI > is sprite within distance to detect each rescue.

This project contains 79 ordinary blocks. Forest Trail is the Stage environment; only the 4 gameplay actors are sprites. The project stores its Stage setting and actor library choices.

Rebuild in 3D and XR Studio:
1. Start a blank 3D project. Select Stage in the lower-right panel, open Choose an Environment, and select Forest Trail. The environment chooser applies the landscape to Stage at scale 22000%.
2. Use Choose a 3D Object for the actors in SETUP.assets only. Pick each row's library model and rename the sprite to its listed name. Set actor scale with Transform > set all scale and position with Transform > go to x/y/z using the listed values (36 position units equal one world unit).
3. Add the World extension for the existing set fog block described in SETUP.haze. Create the variables for all sprites, then build the visible recipes. Indented lines belong inside their enclosing Control block.

VISIBLE BLOCK RECIPES

SPRITE: Forest Ranger
when green flag clicked
set fog to #d5e6ee at distance 150
set Rescued to 0
create text Rescue all three hikers named Mission
set font size of Mission to 64
attach Mission to Forest Ranger
set offset of Mission to x: 0 y: 216 z: 0
go to x: -2340 y: 3 z: 2160
show
set rotation to x: 0 y: 0 z: 0
follow Forest Ranger at distance 900 without turning
repeat until (Rescued = 3)
  if key up arrow pressed? then
    set rotation to x: 0 y: 0 z: 0
    change z position by -18
  if key down arrow pressed? then
    set rotation to x: 0 y: 180 z: 0
    change z position by 18
  if key left arrow pressed? then
    set rotation to x: 0 y: 90 z: 0
    change x position by -18
  if key right arrow pressed? then
    set rotation to x: 0 y: -90 z: 0
    change x position by 18
  if ((x position) > 3780) then
    set x position to 3780
  if ((x position) < -3780) then
    set x position to -3780
  if ((z position) > 3780) then
    set z position to 3780
  if ((z position) < -3780) then
    set z position to -3780
  wait 0.03 seconds


SPRITE: Hiker 1
when green flag clicked
show
wait 0.2 seconds
wait until is Forest Ranger within 180 of Hiker 1?
hide
change Rescued by 1
set text of Mission to (join Hikers rescued:  (join (Rescued)  of 3))


SPRITE: Hiker 2
