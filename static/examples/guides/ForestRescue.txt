Forest Rescue
=============

Reach the three orange hikers along the forest paths. Arrow keys move the ranger. Each rescued hiker disappears; the ordinary Text blocks update the floating mission label. Green flag restarts all hikers. Use AI > is sprite within distance to detect each rescue.

This project contains 56 ordinary visible Scratch blocks. The scenery and every actor come from the 3D library; nothing is uploaded or embedded. No editor, renderer, VM or extension changes are required.

Rebuild: in 3D and XR Studio start a blank 3D project. Click Choose a 3D Object and pick each model listed under SETUP from the library (the worlds are under the Worlds tag), then rename each sprite exactly as listed. Set each sprite's size with Transform > set all scale (the number is the model's biggest side in world units x 100, so a world 220 units wide is 22000) and place it with Transform > go to x/y/z. The maps are measured in world units; multiply positions by 36 for the Scratch blocks (a 220-unit world is 7920 Scratch units wide). Add the World extension: it holds the haze block "set fog to ... at distance ..." that the first script uses. Create the variables below for all sprites. Indented recipe lines belong inside their enclosing Control block.

VISIBLE BLOCK RECIPES

SPRITE: Forest Ranger
when green flag clicked
set fog to #d5e6ee at distance 150
set Rescued to 0
create text Rescue all three hikers named Mission
set font size of Mission to 34
attach Mission to Forest Ranger
set offset of Mission to x: 0 y: 144 z: 0
go to x: -2340 y: 3 z: 2160
show
follow Forest Ranger at distance 900
repeat until (Rescued) = 3
  if key up arrow pressed? then
    change z position by -18
  if key down arrow pressed? then
    change z position by 18
  if key left arrow pressed? then
    change x position by -18
  if key right arrow pressed? then
    change x position by 18
  wait 0.03 seconds


SPRITE: Hiker 1
when green flag clicked
show
wait 0.2 seconds
wait until is Forest Ranger within 180 of Hiker 1?
hide
change Rescued by 1
set text of Mission to join Rescued / 3:  (Rescued)


SPRITE: Hiker 2
when green flag clicked
show
wait 0.2 seconds
wait until is Forest Ranger within 180 of Hiker 2?
hide
change Rescued by 1
set text of Mission to join Rescued / 3:  (Rescued)


SPRITE: Hiker 3
when green flag clicked
show
wait 0.2 seconds
