3D WORLD PROJECTS

Open 3D and XR Studio, then File > Learn > Examples > 3D.

Forest Rescue: arrow keys; reach all three hikers.
Voxel Treasure Hunt: arrow keys; find the gold chest.
Checkpoint Circuit: arrow keys; reach the three gates in order.
Robot Football Practice: arrows drive; stand behind the ball and press Space to kick.
Robot Gate Trail: arrows; visit the three numbered gates.
Obstacle Explorer: arrows; explore and reach the three gates.
Sky Patrol: arrows steer/climb; Space fires. The existing GamePad BLE Android controller is optional.

Every project contains separate scenery and actor sprites. The worlds and every actor are in the 3D library (Choose a 3D Object; the worlds are under the Worlds tag), so you can build each project yourself; the saved project only remembers which library model each sprite uses. Rules are ordinary editable Scratch blocks. Every project except Robot Football Practice starts with the World block "set fog ... at distance ...", which adds a light haze.

Build instructions: ForestRescue.txt, VoxelTreasure.txt, CheckpointCircuit.txt, RobotFootball.txt, RobotSensorTrail.txt (Robot Gate Trail), ObstacleExplorer.txt, sky-patrol.md in this folder. Each guide lists the library models, sizes, starting coordinates, variables and the visible block recipes; sky-patrol.md builds the game in five parts that you can test one by one.

Models and thumbnails: /static/models/3d/world-content/environments/manifest.json and /static/models/3d/world-content/sprites/manifest.json. Sizes use Transform > set all scale (scale = the model's biggest side in world units x 100); positions use Transform > go to x/y/z, in Scratch units (36 per world unit).
