Robot Football Practice
=======================

Arrow keys drive the robot. Approach the football from the side opposite your target goal, then press Space to kick. The ball travels away from the robot, so your approach controls the shot direction. Score through either end goal; shots outside the posts miss. The ball resets after each shot. The visible Operators blocks normalize a direction vector; no physics engine changes are used.

This project contains 98 ordinary blocks. Football Stadium is the Stage environment; only the 2 gameplay actors are sprites. The project stores its Stage setting and actor library choices.

Rebuild in 3D and XR Studio:
1. Start a blank 3D project. Select Stage in the lower-right panel, open Choose an Environment, and select Football Stadium. The environment chooser applies the landscape to Stage at scale 22000%.
2. Use Choose a 3D Object for the actors in SETUP.assets only. Pick each row's library model and rename the sprite to its listed name. Set actor scale with Transform > set all scale and position with Transform > go to x/y/z using the listed values (36 position units equal one world unit).
3. Create the variables for all sprites, then build the visible recipes. Indented lines belong inside their enclosing Control block.

SETUP
{
  "title": "Robot Football Practice",
  "project": "RobotFootball",
  "environment": "football-stadium",
  "stage": {
    "type": "model",
    "name": "Football Stadium",
    "thumbnailURL": "static/examples/thumbnails/world-football-stadium.webp",
    "model3d": {
      "source": "library",
      "glbURL": "static/models/3d/world-content/environments/football-stadium.glb"
    },
    "scale3d": 22000
  },
  "variables": {
    "Score": 0,
    "Player x": 0,
    "Player z": 900,
    "Kick x": 0,
    "Kick z": 0,
    "Kick length": 1
  },
  "assets": [
    {
      "name": "Football Robot",
      "glbURL": "static/models/3d/world-content/sprites/robot-car.glb",
      "scale3d": 280,
      "position": {
        "x": 0,
        "y": 3,
        "z": 900
      },
      "library": "Robot Car"
    },
    {
      "name": "Football",
      "glbURL": "static/models/3d/world-content/sprites/football.glb",
      "scale3d": 70,
      "position": {
        "x": 0,
        "y": 3,
        "z": 0
      },
      "library": "Football"
    }
  ]
}

VISIBLE BLOCK RECIPES

SPRITE: Football Robot
when green flag clicked
go to x: 0 y: 3 z: 900
set Score to 0
create text Approach the ball; Space kicks named Mission
set font size of Mission to 64
attach Mission to Football Robot
set offset of Mission to x: 0 y: 216 z: 0
set rotation to x: 0 y: 0 z: 0
follow Football Robot at distance 1200 without turning
forever
  if key up arrow pressed? then
    set rotation to x: 0 y: 0 z: 0
    change z position by -18
  if key down arrow pressed? then
    set rotation to x: 0 y: 180 z: 0
    change z position by 18
  if key left arrow pressed? then
    set rotation to x: 0 y: 90 z: 0
    change x position by -18
  if key right arrow pressed? then
    set rotation to x: 0 y: -90 z: 0
    change x position by 18
  if ((x position) > 1980) then
    set x position to 1980
  if ((x position) < -1980) then
    set x position to -1980
  if ((z position) > 1368) then
    set z position to 1368
  if ((z position) < -1368) then
    set z position to -1368
  set Player x to (x position)
  set Player z to (z position)
  wait 0.03 seconds


SPRITE: Football
when green flag clicked
go to x: 0 y: 3 z: 0
forever
  wait until (key space pressed? and is Football Robot within 180 of Football?)
  set Kick x to ((x position) - Player x)
  set Kick z to ((z position) - Player z)
  set Kick length to (sqrt of ((Kick x * Kick x) + (Kick z * Kick z)))
  if (Kick length > 18) then
    set Kick x to ((Kick x / Kick length) * 48)
    set Kick z to ((Kick z / Kick length) * 48)
    repeat until (((abs of (x position)) > 1980) or ((abs of (z position)) > 1368))
      change x position by Kick x
      change z position by Kick z
      wait 0.03 seconds
    if (((abs of (x position)) > 1900) and ((abs of (z position)) < 288)) then
      change Score by 1
      set text of Mission to (join Goal! Score:  Score)
    wait 1 seconds
    go to x: 0 y: 3 z: 0
  wait 0.1 seconds
