Robot Gate Trail
================

Use the arrow keys to visit the three checker gates in order. Each gate disappears when reached; the floating label shows progress. Explore the open corridors and equipment around the route. All proximity checks use the existing AI blocks. Green flag starts a new run.

This project contains 82 ordinary blocks. Robot Test Lab is the Stage environment; only the 4 gameplay actors are sprites. The project stores its Stage setting and actor library choices.

Rebuild in 3D and XR Studio:
1. Start a blank 3D project. Select Stage in the lower-right panel, open Choose an Environment, and select Robot Test Lab. The environment chooser applies the landscape to Stage at scale 22000%.
2. Use Choose a 3D Object for the actors in SETUP.assets only. Pick each row's library model and rename the sprite to its listed name. Set actor scale with Transform > set all scale and position with Transform > go to x/y/z using the listed values (36 position units equal one world unit).
3. Add the World extension for the existing set fog block described in SETUP.haze. Create the variables for all sprites, then build the visible recipes. Indented lines belong inside their enclosing Control block.

VISIBLE BLOCK RECIPES

SPRITE: Trail Robot
when green flag clicked
set fog to #d5e6ee at distance 220
set Checkpoints to 0
create text Reach Gate 1, then 2, then 3 named Mission
set font size of Mission to 64
attach Mission to Trail Robot
set offset of Mission to x: 0 y: 216 z: 0
go to x: 0 y: 3 z: 2880
show
set rotation to x: 0 y: 0 z: 0
follow Trail Robot at distance 900 without turning
repeat until (Checkpoints = 3)
  if key up arrow pressed? then
    set rotation to x: 0 y: 0 z: 0
    change z position by -18
  if key down arrow pressed? then
    set rotation to x: 0 y: 180 z: 0
    change z position by 18
  if key left arrow pressed? then
    set rotation to x: 0 y: 90 z: 0
    change x position by -18
  if key right arrow pressed? then
    set rotation to x: 0 y: -90 z: 0
    change x position by 18
  if ((x position) > 3780) then
    set x position to 3780
  if ((x position) < -3780) then
    set x position to -3780
  if ((z position) > 3780) then
    set z position to 3780
  if ((z position) < -3780) then
    set z position to -3780
  wait 0.03 seconds


SPRITE: Gate 1
when green flag clicked
show
wait 0.2 seconds
wait until ((Checkpoints = 0) and is Trail Robot within 180 of Gate 1?)
hide
change Checkpoints by 1
set text of Mission to (join Gates reached:  (join (Checkpoints)  of 3))


SPRITE: Gate 2
when green flag clicked
show
wait 0.2 seconds
wait until ((Checkpoints = 1) and is Trail Robot within 180 of Gate 2?)
hide
change Checkpoints by 1
set text of Mission to (join Gates reached:  (join (Checkpoints)  of 3))


SPRITE: Gate 3
when green flag clicked
show
wait 0.2 seconds
wait until ((Checkpoints = 2) and is Trail Robot within 180 of Gate 3?)
hide
change Checkpoints by 1
set text of Mission to All three gates reached!
