Voxel Treasure Hunt
===================

Follow the open road through the voxel village to the gold treasure chest. Arrow keys move. Reaching the chest collects it and ends movement. Try moving the chest by changing its starting-position blocks.

This project contains 34 ordinary visible Scratch blocks. The scenery and every actor come from the 3D library; nothing is uploaded or embedded. No editor, renderer, VM or extension changes are required.

Rebuild: in 3D and XR Studio start a blank 3D project. Click Choose a 3D Object and pick each model listed under SETUP from the library (the worlds are under the Worlds tag), then rename each sprite exactly as listed. Set each sprite's size with Transform > set all scale (the number is the model's biggest side in world units x 100, so a world 220 units wide is 22000) and place it with Transform > go to x/y/z. The maps are measured in world units; multiply positions by 36 for the Scratch blocks (a 220-unit world is 7920 Scratch units wide). Add the World extension: it holds the haze block "set fog to ... at distance ..." that the first script uses. Create the variables below for all sprites. Indented recipe lines belong inside their enclosing Control block.

SETUP
{
  "title": "Voxel Treasure Hunt",
  "project": "VoxelTreasure",
  "environment": "voxel-valley",
  "variables": {
    "Found": 0
  },
  "assets": [
    {
      "name": "Voxel Valley Scenery",
      "glbURL": "static/models/3d/world-content/environments/voxel-valley.glb",
      "scale3d": 22000,
      "positionScratch": {
        "x": 0,
        "y": 0,
        "z": 0
      },
      "library": "Voxel Valley"
    },
    {
      "name": "Voxel Explorer",
      "glbURL": "static/models/3d/world-content/sprites/voxel-explorer.glb",
      "scale3d": 200,
      "positionScratch": {
        "x": 0,
        "y": 3,
        "z": 2880
      },
      "library": "Voxel Explorer"
    },
    {
      "name": "Treasure Chest",
      "glbURL": "static/models/3d/world-content/sprites/gold-chest.glb",
      "scale3d": 220,
      "positionScratch": {
        "x": 2340,
        "y": 3,
        "z": 0
      },
      "library": "Gold Chest"
    }
  ],
  "haze": {
    "block": "World > set fog to (colour) at distance (distance)",
    "colour": "#d5e6ee",
    "distance": 150,
    "where": "first block after the green flag of Voxel Explorer"
  }
}

VISIBLE BLOCK RECIPES

SPRITE: Voxel Explorer
when green flag clicked
set fog to #d5e6ee at distance 150
set Found to 0
create text Find the gold chest named Mission
set font size of Mission to 34
attach Mission to Voxel Explorer
set offset of Mission to x: 0 y: 144 z: 0
go to x: 0 y: 3 z: 2880
show
follow Voxel Explorer at distance 900
repeat until (Found) = 1
  if key up arrow pressed? then
    change z position by -18
  if key down arrow pressed? then
    change z position by 18
  if key left arrow pressed? then
    change x position by -18
  if key right arrow pressed? then
    change x position by 18
  wait 0.03 seconds


SPRITE: Treasure Chest
when green flag clicked
show
wait 0.2 seconds
wait until is Voxel Explorer within 160 of Treasure Chest?
hide
set Found to 1
set text of Mission to Treasure found!
