Voxel Treasure Hunt
===================

Follow the open road through the voxel village to the gold treasure chest. Arrow keys move. Reaching the chest collects it and ends movement. Try moving the chest by changing its starting-position blocks.

This project contains 54 ordinary blocks. Voxel Valley is the Stage environment; only the 2 gameplay actors are sprites. The project stores its Stage setting and actor library choices.

Rebuild in 3D and XR Studio:
1. Start a blank 3D project. Select Stage in the lower-right panel, open Choose an Environment, and select Voxel Valley. The environment chooser applies the landscape to Stage at scale 22000%.
2. Use Choose a 3D Object for the actors in SETUP.assets only. Pick each row's library model and rename the sprite to its listed name. Set actor scale with Transform > set all scale and position with Transform > go to x/y/z using the listed values (36 position units equal one world unit).
3. Add the World extension for the existing set fog block described in SETUP.haze. Create the variables for all sprites, then build the visible recipes. Indented lines belong inside their enclosing Control block.

SETUP
{
  "title": "Voxel Treasure Hunt",
  "project": "VoxelTreasure",
  "environment": "voxel-valley",
  "stage": {
    "type": "model",
    "name": "Voxel Valley",
    "thumbnailURL": "static/examples/thumbnails/world-voxel-valley.webp",
    "model3d": {
      "source": "library",
      "glbURL": "static/models/3d/world-content/environments/voxel-valley.glb"
    },
    "scale3d": 22000
  },
  "variables": {
    "Found": 0
  },
  "assets": [
    {
      "name": "Voxel Explorer",
      "glbURL": "static/models/3d/world-content/sprites/voxel-explorer.glb",
      "scale3d": 200,
      "position": {
        "x": 0,
        "y": 3,
        "z": 2880
      },
      "library": "Voxel Explorer"
    },
    {
      "name": "Treasure Chest",
      "glbURL": "static/models/3d/world-content/sprites/gold-chest.glb",
      "scale3d": 220,
      "position": {
        "x": 2340,
        "y": 3,
        "z": 0
      },
      "library": "Gold Chest"
    }
  ],
  "haze": {
    "block": "World > set fog to (colour) at distance (distance)",
    "colour": "#d5e6ee",
    "distance": 150,
    "where": "first block after the green flag of Voxel Explorer"
  }
}

VISIBLE BLOCK RECIPES

SPRITE: Voxel Explorer
when green flag clicked
set fog to #d5e6ee at distance 150
set Found to 0
create text Find the gold chest named Mission
set font size of Mission to 64
attach Mission to Voxel Explorer
set offset of Mission to x: 0 y: 216 z: 0
go to x: 0 y: 3 z: 2880
show
set rotation to x: 0 y: 0 z: 0
follow Voxel Explorer at distance 900 without turning
repeat until (Found = 1)
  if key up arrow pressed? then
    set rotation to x: 0 y: 0 z: 0
    change z position by -18
  if key down arrow pressed? then
    set rotation to x: 0 y: 180 z: 0
    change z position by 18
  if key left arrow pressed? then
    set rotation to x: 0 y: 90 z: 0
    change x position by -18
  if key right arrow pressed? then
    set rotation to x: 0 y: -90 z: 0
    change x position by 18
  if ((x position) > 3780) then
    set x position to 3780
  if ((x position) < -3780) then
    set x position to -3780
  if ((z position) > 3780) then
    set z position to 3780
  if ((z position) < -3780) then
    set z position to -3780
  wait 0.03 seconds


SPRITE: Treasure Chest
when green flag clicked
show
wait 0.2 seconds
wait until is Voxel Explorer within 160 of Treasure Chest?
hide
set Found to 1
set text of Mission to Treasure found!
